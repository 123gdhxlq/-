# 历史与连续性检查机制

这部小说采用“自动扫描 + 人工审校 + 章节台账”三层机制。自动检查只能发现明显穿帮词，不能替代历史研究。

## 每章写作前

1. 在 `docs/历史事实台账.json` 中确认本章会用到的机构、称谓、药材和医疗行为。
2. 给新增事实标注类型：
   - **史实**：能在古籍或可靠研究中找到依据。
   - **时代推断**：没有直接材料，但由同期制度和技术推得；正文避免写成唯一事实。
   - **虚构**：人物、案件、组织或因剧情需要创造的制度；不冒充真实历史。
3. 如果事实属于“史实”或“时代推断”，在本章工作记录中补充来源。

## 每章写作后

- 运行 `python tools/check_story_consistency.py`。
- 检查自动报告中的禁止词、未完成标记和章节标题问题。
- 对照以下五项人工清单：
  1. **时间**：这一章发生在元丰七年何时？是否误用了后世机构或事件？
  2. **地点**：汴京、汴河、城郊和药铺的空间关系是否合理？
  3. **身份**：人物的称谓、服饰、行动权限是否符合身份？
  4. **医疗**：药材、病症、诊断和处置是否符合当时可获得的知识与工具？
  5. **虚构边界**：虚构的宁王、裴家和案件有没有被叙述成真实史实？

## 每五章审校一次

- 重新核对本阶段新增的所有历史事实。
- 把不确定内容移到“待核对”清单，不让它悄悄变成确定事实。
- 检查人物年龄、伤势、伤口恢复时间、行程和证据链是否互相矛盾。
- 确认短剧改编时删掉的段落不会破坏历史前提。

## 提交前门槛

一次提交至少要满足：

- 自动检查通过。
- 没有 `TODO`、`TBD` 或“待补”文字留在正文。
- 新增历史事实有出处、推断标记或虚构说明。
- 正文没有使用 `docs/历史考据.md` 列出的禁用机构和现代器械。
- 提交说明写清本次新增的历史范围和仍未核对的部分。

## 发现错误后的处理

发现史实错误时，不直接在后文打补丁。先修改历史事实台账和考据文档，再回看所有受影响章节，最后用一个独立提交记录修正原因。
