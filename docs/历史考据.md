# 历史考据基线

## 时空定位

正文暂定在**北宋元丰七年（1084）**，主要地点是汴京及其城郊。元丰年间的制度、机构和生活细节作为历史锚点；沈知微、萧景珩、裴彦廷、顾承安及其阴谋均为虚构。

选择元丰年间，是因为北宋的城市商业、药物管理和医学教育都已经具备较成熟的制度背景。小说可以让女主接触真实存在的药材、方书、药局和城市交通，同时保留虚构案件的空间。

## 可以直接使用的历史锚点

### 1. 医学教育与官方机构

北宋有太医局，沿袭隋唐太医体系，宋代逐步承担医学教育功能；熙宁、元丰时期继续扩充，设有教授、医师、针师、按摩师等分工。正文可以写“太医局”作为京师的官方医学机构，但沈知微作为民间女医不能直接等同于太医局学生或官医。

参考：

- 《宋史》相关职官记载
- 《宋会要辑稿·职官》
- 《太医局》条目所引制度资料：https://zh.wikipedia.org/wiki/太醫局

### 2. 药局与方书

《太平惠民和剂局方》记录的是宋代官方药局方书传统。现存版本的“太平惠民局”名称与南宋绍兴年间有关；元丰年间写作时，正文使用“药局”“熟药所”“太医局方”等较稳妥，避免把后来的“太平惠民局”名称提前到 1084 年。

参考：《太平惠民和剂局方》序文及相关校记：

- https://zh.wikisource.org/wiki/太平惠民和劑局方

### 3. 汴京城市生活

孟元老《东京梦华录》成书晚于元丰七年，但记载了北宋汴京的街市、酒楼、药铺、河渠、夜市和节令风俗。正文把它作为城市生活的参照，不把书中所有具体事件倒推成 1084 年已经发生。

参考：

- 《东京梦华录》：https://zh.wikisource.org/wiki/東京夢華錄

### 4. 医疗方法与药材

正文可使用脉诊、针刺、艾灸、热敷、煎药、外敷、止血、包扎、清创等当时已有的治疗方式。常见药材写作时优先选择甘草、桂枝、生姜、大黄、黄连、当归、川芎、附子、乌头、艾叶等在本草传统中有明确记载的药材，但剂量、炮制和适应证不把现代医学结论强行套入古代。

可参考：

- 《本草图经》
- 《太平圣惠方》
- 《苏沈良方》
- 《太平惠民和剂局方》

### 5. 婚姻、名节与诉讼

“退婚”和“名节”在小说中作为家族和地方社会压力使用；具体诉讼程序不简化成现代法庭。女主若要自证，需要依靠证人、药包、文书、医者记录、官府验看和权贵之间的利益关系，而不是现代意义上的指纹、监控和实验室报告。

制度参照：

- 《宋刑统》
- 《宋会要辑稿》相关刑法、职官与礼制材料

### 6. 王爵与称谓

萧景珩是虚构的北宋宗室“宁王”。正式场合使用“宁王殿下”或“殿下”；民间称谓可以根据人物身份使用“王府”“宗室”“王府长史”等。小说不把萧景珩写成真实历史人物，也不借他的虚构经历解释真实政治事件。

## 明确避免的错误

- 不写太医院、太平惠民局、女医署等机构在元丰七年已经完全按后世形态存在。
- 不使用抗生素、输液、注射器、听诊器、X 光、现代消毒水和现代法医术语。
- 不让银针“验毒”；银针只能作为针刺工具或普通金属器具。
- 不把现代急救术写成宋代常识；沈知微掌握它，其他人会感到陌生和惊疑。
- 不把民间女医写成拥有现代职业权利；她必须承担名声、礼法和行医资格的压力。

## 虚构边界

宁王、裴家、顾家、济安堂、漕运军药走私案和“女医署”结局均为架空故事。若后续把故事改成严格历史小说，应将宁王改为虚构宗室封号，并在卷首注明“人物与案件为虚构”。
