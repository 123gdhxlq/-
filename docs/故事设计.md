# 故事设计：医心藏王

## 一句话梗概

现代急诊女医生沈知微穿越到北宋元丰七年，刚醒来就被未婚夫当众退婚并诬为毒害权贵。她用急救术救活裴家小姐，仍被推成替罪羊；逃亡途中，她救下一个身负重伤的药材商，后来才知道对方是暗查军药走私的宁王。

## 三条主线

- **洗冤线**：从被退婚的低位养女，到凭证据在公堂上拆穿假病案。
- **医馆线**：从借药材救人，到重开济安堂，逐渐成为汴京民间女医的名号。
- **权谋线**：从一包毒药和一支弩矢，追到漕运、军药和裴家伪造军报的阴谋。

## 主要人物

- 沈知微：现代急诊医生，冷静、果断，但不熟悉宋代礼法。
- 萧景珩：虚构的宁王，化名萧七，负责调查军药和漕运账目。
- 裴彦廷：户部尚书，裴家家主，利用假病案掩盖账目。
- 裴婉宁：裴家嫡女，既是第一案受害者，也是最初的伪证者。
- 顾承安：沈知微的原未婚夫，为攀附裴家公开退婚。
- 阿芷：济安堂小学徒，熟悉药材与街巷，是女主的第一个帮手。

## 短剧节拍

前十集分别完成：公开退婚、急救、药包陷害、押解遇袭、雨夜救王、重开医馆、漕运线索和宁王身份揭示。每两章可压缩为一集，每章结尾必须留下下一步行动问题。
