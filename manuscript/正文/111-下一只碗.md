# 第一百一十一章　下一只碗

第三重锁迟迟没有落下。

沈知微让萧景珩守住石门，自己带谢简和陆知衡退到南库高处。水已漫过木箱脚，纸册只能再撑一刻。她把第三页手稿交给陆知衡，让他用油纸重新包好，又让阿芷把药膏、完整药碗和名册分开背负。

“若门开不了，先把药碗送出去。”沈知微说。

萧景珩看她：“你呢？”

“我留下看水位。”

“不行。”

“若有人从水道进来，必须有人听见。”

门外忽然传来两声短促的敲击，随后是赵循压低的声音：“沈姑娘，第三重锁的钥匙在陈内侍手里，但他不会开。”

“你想换什么？”

“我要第三册里关于赵循的那一页。”

沈知微取出拓纸：“你已经知道我们手里没有完整第三册。”

“我知道你有一份拓纸。”赵循道，“那份拓纸上有我的名字。”

“你怕名字落到皇帝手里？”

“我怕名字落到陈内侍手里。他要把所有改档的罪推给我。”

陈内侍在门外冷笑：“赵循，你以为替人改几行时辰，便能把自己摘出去？”

赵循没有回答。石门外传来脚步移动声，像两人正在争抢钥匙。

沈知微把一张空白纸塞进门缝：“赵循，钥匙送进来，我给你看拓纸。”

“我凭什么信你？”

“你不信我，也不信陈内侍。可你知道，只有我会先救你再问你的罪。”

门缝下滚进一枚铜钥匙。沈知微没有立刻去拿，而是先用木夹将钥匙拨到白纸上。钥匙齿口沾着灰黑色油泥，油泥中混着一粒白砂。

“钥匙刚从北门水道取出。”她说，“赵循没有说谎。”

萧景珩用钥匙打开第三重锁，石门只开了一条缝。水流猛地冲入，陈内侍和赵循的影子同时出现在门外。

沈知微先把陆安拉进门内，再让周七拖出吴守门。谢简没有逃，而是站在门缝旁看着陈内侍。

“谢简。”陈内侍道，“你把第三页交给他们，便没有活路。”

谢简回答：“我早就没有路了。”

他将一只粗陶盏扔向陈内侍。粗陶盏在石门外碎开，里面没有药，只有一张写着南岸仓场编号的纸。

陈内侍低头看纸，赵循却趁机推开他，转身逃进水道。

沈知微追出两步，只看见赵循把一只白瓷碗放进第三道水闸旁的木槽。

“下一只碗在军药仓场。”赵循回头道，“你们若想知道谁真正换过王妃的药，就去找那只碗。”

水闸轰然落下，赵循的身影被水雾吞没。

沈知微站在木槽前，看到碗底刻着一个新的编号：**第三仓，七月初五。**

南库的交换没有结束，只把下一条线推向了军药仓场。

她没有立刻把白瓷碗拿起，而是先用布巾擦去碗沿的水珠。碗口留着一道极细的褐色痕迹，像药汁干后又被水冲开；痕迹旁还有两粒未化尽的细砂。军药仓场的碗若只是装药，不会带着南库水道里的砂，除非有人在水下把碗从另一只木槽中转过来。这样一来，赵循留下的便不只是地点，还有一条能复验的路径。

陆知衡翻开名册，找到“七月初五”一栏：“这日是军药仓场换值，第三仓由西班直押运。若碗底编号是真的，守仓的人应当知道谁在那天动过药箱。”

谢简却盯着碗底，脸色慢慢变白：“第三仓不是存药的地方，是退回药材暂放之处。那里没有正式封条，只有仓吏的私记。”

“也就是说，任何人都能把一只碗换进去。”沈知微说。

萧景珩回头看水闸：“赵循把我们引到军药仓场，是想让我们查碗，还是想让我们在那里碰见真正的换药人？”

门外的水声忽然变急，陈内侍的人正在重新封锁南库。沈知微把白瓷碗交给阿芷，用油纸包住碗底，随后将那张写有仓号的纸折成三层，分别交给陆知衡、谢简和自己。三人只要有一人活着，线索便不会一并断掉。

她最后看了一眼水闸落下的方向：“天亮前去不了军药仓场，就会错过七月初五留下的私记。可若现在出库，陈内侍一定会沿河追来。”

高处漏刻滴下最后一声水响。军药仓场的第三仓，究竟还藏着谁的手印，已经成了他们必须在天亮前回答的问题。
