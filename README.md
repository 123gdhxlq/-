# 《医心藏王》

这是一部以北宋为历史底色的穿越医女小说，目标是后续改编为 30 集短剧。

## 当前进度

- 历史考据基线：见 `docs/历史考据.md`
- 历史事实台账：见 `docs/历史事实台账.json`
- 历史与连续性检查机制：见 `docs/历史一致性检查机制.md`
- 故事设计：见 `docs/故事设计.md`
- 正文：已完成第一卷开篇七十一章（当前正文约 79,718 字）

## 检查命令

在仓库根目录运行：

```bash
python tools/check_story_consistency.py
```

该命令只扫描 `manuscript/正文/`，检查明显的后世机构、现代医疗器械、现代技术词、未完成标记和每章至少 1000 字的正文长度。它不能替代逐章历史考据；每五章仍需人工复核历史事实台账。

## 核心设定

现代急诊女医生沈知微穿越到北宋元丰七年，成为汴京城外济安堂的养女。她刚醒来，就面对未婚夫顾承安当众退婚，以及“以药害人”的罪名。她救下被杏仁酥碎壳噎住的裴家小姐，却被人把砒霜纸包塞进袖中，推成谋害权贵的凶手。

押解途中，沈知微又救下一个身负弩伤的陌生人。对方自称药材商萧七，真实身份却是正在暗查军药和漕运账目的宁王。

## 写作约束

1. 北宋制度、机构、城市生活和医药知识以考据文档为准。
2. 真实历史与虚构人物分开：阴谋、人物、案件为小说虚构，不冒充史实。
3. 医疗场景写观察、判断、处置和限制，不使用现代设备或现代医学名词直接替代行动。
4. 每章推进一个主要事件，章末留下一个必须在下一章处理的问题。
5. 后续短剧改编时，每两章作为一集的基础单元。
